# RING OF FURY — 3D格闘ゲーム

鉄拳・バーチャファイター風の3D対戦格闘ゲームです。Three.js 製、ブラウザでそのまま遊べます（ビルド不要）。

## 遊び方

リポジトリ直下で静的サーバーを起動して `index.html` を開くだけです。

```bash
# どちらか好きな方法で
npx serve .
# または
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000`（または表示されたURL）を開きます。

## ゲームモード

- **1P vs CPU** — 難易度3段階（よわい / ふつう / つよい）
- **2P 対戦** — 1つのキーボードで2人対戦

ルールは **2本先取・60秒制**。体力を削り切る（KO）か、ステージ外に押し出す（**リングアウト**）か、時間切れ時に体力が多い方がラウンドを取ります。

## 操作方法

| 操作 | 1P | 2P |
|---|---|---|
| 移動（前後） | A / D | ← / → |
| サイドステップ（軸移動） | Q / E | , / . |
| ジャンプ | W | ↑ |
| しゃがみ | S | ↓ |
| パンチ（上段・高速） | F | K |
| キック（中段・中速） | G | L |
| 必殺技（大ダメージ） | H | O |
| 投げ（ガード不能） | T | I |
| ガード | Space | M |
| ポーズ | Escape | — |
| BGM ON/OFF | B | B |

### コンボ・技表

| 入力（1P表記） | 技 | 備考 |
|---|---|---|
| F → F → F | ジャブ → ストレート → アッパー | 3段目でダウンを奪う |
| F → G | パンチ → ミドルキック | 連携 |
| G → G | ミドル → ハイキック | 2段目でダウン |
| S + F | しゃがみパンチ | **下段**・高速 |
| S + G | 足払い | **下段**・ダウンを奪う |
| ジャンプ中 F / G | ジャンプ攻撃 | 中段・しゃがみガードを崩す |
| T（密着） | 投げ | **ガード不能**・しゃがみには空振り |
| H | 必殺技 | キャラ固有・ダウンを奪う |

### 駆け引きの三すくみ

- **立ちガード**は上段・中段を防ぐが、**下段**と**投げ**に弱い
- **しゃがみガード**は下段を防ぎ上段をかわすが、**中段**（キック・必殺技・ジャンプ攻撃）に弱い
- 攻撃を**ガードさせ続ける**と投げ・下段のチャンス。**サイドステップ**で軸をずらせば攻撃自体を空振りさせられる
- ダウン中・起き上がり中は無敵。端に追い詰めて**リングアウト**も狙える

## 技術構成

- **Three.js**（`lib/` に同梱、ビルド・バンドラ不要）
- キャラクターモデルはプロシージャル生成（関節階層リグ + キーフレームアニメ）
- 効果音 **＆ BGM** は WebAudio でリアルタイム合成（音声ファイル不要）。BGM はシーンごとに曲調が変化（タイトル＝荘厳な和風マイナー／戦闘＝疾走系／勝利＝ファンファーレ）。`B` キーでいつでも ON/OFF
- カメラは2人を結ぶ軸に常に垂直な追従カメラ（鉄拳/VF方式）

```
index.html        # UI・スタイル・エントリポイント
src/main.js       # ゲーム状態管理・ラウンド制・カメラ・HUD
src/fighter.js    # キャラモデル生成・アニメーション・戦闘ロジック
src/characters.js # 12人のロスター定義
src/stage.js      # 闘技場ステージ
src/input.js      # キーボード入力
src/ai.js         # CPU AI
src/audio.js      # 効果音合成
```
